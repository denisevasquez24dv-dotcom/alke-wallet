Alke wallet 
Descripción:Alke Wallet es una aplicación Front-End de billetera digital que permite a los usuarios gestionar sus activos financieros de manera segura y sencilla, los usuarios pueden iniciar seción, enviar dinero a contactos y consultar su historial de tansacciones.
Tecnologías utilizadas:
-HTML
-CSS 
-JavaScript
-Bootstrap 
-JQuery 

Funcionalidades Principales 
-Registro e inicio de Sesión con credenciales seguras.
-Visualización y gestión de saldo disponible.
-Realizar depositos y retiros simulados 
-Enviar dinero a contactos dentro de la aplicación.
-Visualizar historial completo de las transacciones.
-Diseño responsivo para adaptarse a diferentes dispositivos.

Deciciones Técnicas 
El proyecto fue desarrollados utilizando tecnologías Front-end como HTML,css y JavaScript para similar el funcionamiento de una billetera digital sin conexión a un backend.
Se utilizo bootstrap para facilitar el diseño responsivo y mejorar la interfaz de usuario mediante componentes como nanvar, cards y formularios estilizados. 
Jquery fue implementado para mejorar la experiencia de usuario mediante animaciones, efectos visuales y manipulación dinamica del DOM como mensajes interactivos y auto completado de contactos.
El almacenamineto de datos se realizó utilizando LocalStorage del navegador para simular persistencia de información como saldo y transacciones.
